# Tổng hợp kết quả kiểm thử

Chưa có dữ liệu. Điền sau khi đã có các file kết quả của từng người.

## Theo người nói

Chênh lệch trung bình = tổng giá trị tuyệt đối của (điểm app - điểm người nghe) chia cho số lần đọc. Số càng nhỏ thì app càng sát với người nghe.

| Người nói | Giọng / vùng miền | Số lần đọc | Chênh lệch trung bình (yên tĩnh) | Chênh lệch trung bình (ồn) |
| --- | --- | --- | --- | --- |
| | | | | |

## Độ chính xác khi đánh dấu âm sai

Tỷ lệ đồng ý = số âm app đánh dấu sai mà người nghe đồng ý, chia cho tổng số âm app đã đánh dấu sai.

| Tổng số âm app đánh dấu sai | Số âm người nghe đồng ý | Tỷ lệ đồng ý |

| | | |
